# Makeup Mantra - Professional Bridal Makeup Landing Page

A modern, responsive landing page for Makeup Mantra, a premium makeup studio in Karnal, built with Next.js 14 App Router and Tailwind CSS.

## 🌟 Features

- **Modern Design**: Premium gradient backgrounds, glassmorphism effects, and smooth animations
- **Fully Responsive**: Mobile-first design that looks great on all devices
- **SEO Optimized**: Comprehensive meta tags, semantic HTML, and proper heading structure
- **Performance**: Optimized images with Next.js Image component
- **Static Export**: No backend required, ready for Vercel deployment

## 📋 Sections

1. **Hero** - Eye-catching introduction with CTA button
2. **About** - Studio information with stats
3. **Services** - 4 service cards (Bridal, Party, Engagement, HD/Airbrush)
4. **Gallery** - 6 beautiful makeup portfolio images
5. **Testimonials** - 3 client reviews with ratings
6. **Contact** - Business details with click-to-call functionality
7. **Footer** - Copyright information

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed on your system

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
npm start
```

## 🌐 Deploy to Vercel

### Option 1: Deploy via Vercel CLI

1. Install Vercel CLI (if not already installed):
```bash
npm i -g vercel
```

2. Deploy to production:
```bash
vercel --prod
```

### Option 2: Deploy via Vercel Dashboard

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repository
4. Vercel will automatically detect Next.js and deploy
